## Project Overview

A production-grade **4-agent agentic pipeline** that automatically detects, analyzes, fixes, and tests bugs in source code. The pipeline orchestrates specialized agents in a checkpoint-based workflow with conditional execution—skipping unnecessary phases when no bugs are detected or no changes are applied.

**Pipeline Flow**: Research Verifier → Bug Fixer → (if changes made) Security Verifier + Unit Test Generator (parallel)

The system is **general-purpose** and language-agnostic, auto-detecting code language and framework, making it applicable to any codebase. Demonstrated on an **Order Management API** with intentional bugs across validation, state machines, and comparisons.

---

## 🎯 The 4-Agent Pipeline

| Agent | Role | Scope | Output |
|-------|------|-------|--------|
| **Research Verifier** | Analyzes source code to identify bugs | Code-logic bugs only (validation, state machines, comparisons, data handling) | `verified-research.md` + `implementation-plan.md` |
| **Bug Fixer** | Applies fixes sequentially from plan | Modifies code AND updates tests to expect correct behavior | `fix-summary.md` + modified source code |
| **Security Verifier** | Scans for security vulnerabilities | OWASP Top 15 + injection, secrets, XSS/CSRF, unsafe deps | `security-report.md` |
| **Unit Test Generator** | Generates tests for changed code | FIRST principles (Fast, Independent, Repeatable, Self-validating, Timely) | `test-report.md` + test files |

### Key Characteristics

- **Checkpoint-Based Fixing**: Each fix is tested immediately; failures trigger retry or rollback
- **Conditional Execution**: Pipeline skips phases if no bugs found or no changes applied
- **End-to-End Integration**: Agent ensures fixes are complete (not partial)—validators are wired up, tests updated to match correct behavior
- **Integration Gap Detection**: Research agent identifies unused functions, dead code, missing wiring between layers
- **Parallel Verification**: Security & test agents run simultaneously (after fixes applied)
- **Language-Agnostic**: Auto-detects language/framework; works with any codebase

## ✨ Key Features

### Pipeline Orchestration

- **Single-Command Execution**: `npm run pipeline` (dry-run) or `npm run pipeline:execute` (real fixes)
- **Conditional Logic**: Skips unnecessary phases based on research and fix results
- **Parallel Verification**: Security & test agents run simultaneously after fixes
- **Detailed Logging**: All steps logged to `pipeline-execution.log` + console output
- **Checkpoint-Based Safety**: Each fix has a checkpoint for rollback on failure

### Sample Application (Order Management API)

**Before Pipeline**: 2 failing integration tests + multiple validation gaps

**Representative Bug Fixes**:

1. **Validation Gap** (HIGH severity)
   - Problem: `createOrder()` accepted empty `orderedItems` arrays
   - Before: `OrderService.createOrder('cust', [], 'addr')` → accepted
   - After: Throws error with message `"orderedItems must not be empty"`
   - Impact: Prevents invalid orders from entering system

2. **State Machine Violation** (HIGH severity)
   - Problem: Status transitions allowed any state → any state (e.g., Sent → Processing)
   - Before: Could transition backward illegally
   - After: Only valid sequences allowed (New → Processing → InDelivery → Sent)
   - Impact: Enforces order workflow rules

**Results**: 
- ✅ All 5 bugs fixed
- ✅ Integration tests updated to expect correct behavior
- ✅ 95%+ code coverage for changed code
- ✅ Security scan completed (no critical issues in app)

### Agent Capabilities

**Research Verifier**:
- Static analysis of code logic (validation, state machines, comparisons, data handling)
- Integration gap detection (functions not called, unused imports)
- Test-driven research (runs tests to identify failures)
- Severity assessment using custom skill

**Bug Fixer**:
- Flexible plan parsing (handles various documentation formats)
- Sequential fix application with checkpoints
- Retry logic (up to 2 attempts per fix with alternative approaches)
- **Complete fixes**: Updates tests AND wires up new validators in service layer
- Rollback on persistent failure

**Security Verifier**:
- OWASP Top 15 vulnerability scanning
- Task-specific checks: injection, hardcoded secrets, insecure comparisons, missing validation, unsafe deps, XSS/CSRF
- Severity levels: CRITICAL → HIGH → MEDIUM → LOW → INFO
- Incremental scans (changed files only on subsequent runs)

**Unit Test Generator**:
- Language/framework auto-detection
- FIRST-principle test generation
- 95%+ coverage targeting for changed code
- Test types: happy path + error cases + edge cases
- Before/after comparison metrics

Framework for high-quality tests across languages/frameworks:
- **Fast**: Mocked dependencies, no slow I/O
- **Independent**: Self-contained, run in any order
- **Repeatable**: Deterministic, no random data
- **Self-Validating**: Clear assertions, no manual inspection
- **Timely**: Tests written for changed/new code
- **Used by**: Unit Test Generator agent

Both skills are **general-purpose** (not tied to specific bugs or projects) and include language-agnostic guidance with framework-specific examples.

## 🔍 Agent Design Principles

### General-Purpose, Not Project-Specific
- Agents auto-detect language/framework
- Skills use universal criteria (not tied to specific bugs)
- Integration gap detection works for any codebase
- Extensible to C#, Go, Python, Java, Rust, etc.

### Complete End-to-End Fixes
- Bug Fixer agent ensures fixes are COMPLETE:
  - Applies code changes
  - Updates tests to expect correct behavior
  - Wires up new validators/utilities in service layer
  - Verifies integration between layers

### Integration Gap Detection
- Research Verifier identifies unused functions and dead code paths
- Catches scenarios like "validator exists but isn't called"
- Prevents partial/incomplete fixes

### Conditional Pipeline Execution
- **Phase 1 (Research)**: Always runs
- **Phase 2 (Bug Fixer)**: Only if bugs found
- **Phase 3-4 (Verification)**: Only if changes made
- Saves time and compute on clean codebases
